# Panduan Santri

Situs catatan dan dokumentasi pengetahuan, dibangun dengan Astro.

## Menjalankan secara lokal

```sh
npm install
npm run dev
```

Buat build produksi dengan `npm run build`.

## GitHub Pages

Situs dipublikasikan di https://naufaruqi.github.io/panduan_santri/.
Setiap push ke branch `master` akan menjalankan workflow
`.github/workflows/deploy.yml`.
