## Apa Itu Astro?

Astro adalah framework web yang dapat digunakan untuk
membangun situs berbasis konten, termasuk blog.

## Mengapa Menggunakan Markdown?

Markdown memungkinkan kita menulis artikel dengan
format sederhana tanpa harus menulis HTML secara manual.

## Kesimpulan

Astro menyediakan cara terstruktur untuk memisahkan
konten artikel dari tampilan website.
